# 进口大豆运输成本分析

方法沿用 `crude-freight-cost` 的四步：先定口径，再换算，再拆解，最后检验。数字分级（A/B/C）、观测类型分开（直接报价、模型估计、推算、未核实）、不同基准不拼接，这些规则同样适用。大豆和原油不同的地方都写在下面。

## 第 0 步：先定口径

- **单位**：升贴水和 CBOT 用美分/蒲式耳，运费用美元/吨。1 吨 = 36.7437 蒲，美元/吨 = 美分/蒲 × 0.367437。
- **价格层级**：FOB 升贴水（装港船上交货）→ CNF 升贴水（= FOB + 海运费，Mysteel 报的就是这个）→ CNF 价（CBOT + CNF 升贴水，美元/吨）→ 到港完税成本（元/吨）。**运费已经包含在 CNF 升贴水里**，不能在 CNF 之上再加一次运费。
- **航线和船型**：巴西→中国看粮食航线 P8（桑托斯→青岛，巴拿马型 6.6 万吨）；美湾和美西北→中国看对应的粮食航线。2–7 月以巴西为主，9 月至次年 1 月以美国为主。
- **船期与运费时点**：CNF 报价对应的是未来某个船期。最近的船期可以用即期运费近似；远月船期必须用远期运价（P8 FFA 或经纪商远期报价），不能套即期。

## 第 1 步：识别运费的货种（最常见的错误）

钢铁类网站发布的“巴西至中国海运费”通常是**铁矿石**运费（海岬型 C3，与“西澳至中国”C5 并列发布），比大豆粮食航线低约 25–30%。2026-09 的实测：Mysteel 钢铁网 42.22 美元/吨 ≈ C3 42.96，而 P8 为 56.53。误用会把运费低估约 39 美分/蒲。拿到运费先确认三点：货种、船型、装卸港。

## 第 2 步：换算与拆分（用脚本）

```bash
python3 scripts/soy_calc.py conv --cents-bu 154 --usd-t 56.5          # 单位换算
python3 scripts/soy_calc.py split --cnf 318 --freight-usd-t 55.46       # CNF 拆出隐含 FOB
python3 scripts/soy_calc.py split --cnf 318 --fob 160                   # 已知 FOB 时反推隐含运费
python3 scripts/soy_calc.py landed --cbot 1287.5 --cnf 318 --fx 6.7367 --port 100 --ins 0.001 --freight-usd-t 55.46
python3 scripts/soy_calc.py curve --cnf-csv <CNF表> --freight-csv <运费表> --route P8
python3 scripts/soy_calc.py pass  --cnf-csv <CNF表> --freight-csv <运费表> --shipment 2026-11
```

到港完税成本 = CNF 价 ×（1 + 保险费率）× 汇率 ×（1 + 关税）×（1 + 9% 增值税）+ 港杂费。
- 巴西大豆关税按最惠国 3%；美国大豆的额外关税随政策变化，每次都要核实当期税率。
- 关税和增值税以 CIF 为基数，所以运费每涨 1 美元/吨，完税成本约涨 1 × 汇率 × 1.1227 元/吨。

CSV 格式：
- **CNF 表**：`obs_date, origin, shipment(YYYY-MM), ref_contract, cnf_cents_bu, source, tier, note`
- **运费表**：`obs_date, route, cargo, vessel, usd_t, obs_type, tier, source_desc, source_url, note`

示例见 `references/data_2026/`。

## 第 3 步：成本拆全

| 项目 | 说明 |
|---|---|
| 海运费 | 粮食航线美元/吨；2026-09 底巴西→中国约 55–58 美元/吨 ≈ 151–157 美分/蒲 |
| FOB 升贴水 | 含产地内陆运费（巴西卡车、美国驳船和铁路）、港口费用和供需溢价 |
| 保险、损耗 | 保险约 0.1%，损耗按合同 |
| 关税、增值税 | 不属于运输成本，但会放大运费对完税成本的影响（×1.1227） |
| 港杂、港口→工厂短驳 | 按实际账单，几十到一百多元/吨 |
| 滞期、在途资金 | 巴西→中国约 35–45 天，在途资金占用不可忽略 |

## 第 4 步：运费的影响

- **占比**：运费 ÷ CNF 价、运费 ÷ CNF 升贴水、运费 ÷ 完税成本，三者分开写。2026-10-08 的 11 月船期分别约 9.4%、48% 和 9.2%。
- **由谁承担**：比较 ΔCNF 和 Δ运费。CNF 涨幅小于运费涨幅时，差额由 FOB 走弱吸收，即卖方承担。用 `pass` 子命令计算，至少需要 4 组同日配对。
- **对期货的影响**：运费通过进口成本影响压榨利润（豆粕、豆油期货 m、y），路径长、有时滞；豆二（b）以进口大豆为交割标的，更直接。结论要写明样本量，没有日度数据时只作方向判断。

## 第 5 步：检验

`python3 scripts/backtest.py` 检查单位换算、完税成本公式、运费来源一致性、货种识别和拆分结果的合理性，结果见 `references/validation.md`。每次新增数据后都要重跑。

## 输出格式

```
# <产地> 进口大豆运输成本（数据截止：YYYY-MM-DD）
## 结论（3 行以内）
## 运费：数值、航线、船型、货种、日期、来源等级
## CNF 拆分：各船期 CNF、所用运费（即期还是远期）、隐含 FOB、可信度
## 到港完税成本与运费占比（注明汇率、税率、港杂假设）
## 运费的影响：由谁承担、对压榨利润和期货的影响（注明样本量）
## 可靠性检查与缺口
```

## 与 cnf skill 配合

cnf skill 更新 CNF 升贴水表之后，把表导出成上面的 CSV 格式，加上同日的大豆运费（Mysteel 农产品或 Baltic P8；**不要用钢铁网的“巴西至中国”**），运行 `curve` 和 `pass` 即可得到运费拆分和传导结果。
