## 复算

```bash
python3 scripts/build_trend_data.py          # 从两个手工文件重新生成全部派生文件
python3 scripts/freight_calc.py ws --ws 1157.5 --flat 20.21 --api 33           # 单点核对：直接报价
python3 scripts/freight_calc.py ws-from-tce --tce 1412600 --bunker 840          # 单点核对：模型估计
python3 scripts/backtest.py                  # 模型能否复现 Baltic 公布的 (WS, TCE) 配对
```

## 公式与参数

- 直接报价：美元/桶 = WS × 20.21 ÷ 100 ÷ 7.3194。平准费率 20.21 由 CT1 7/6 的 56.98 美元/吨 ÷ WS281.94 反推，桶/吨按 API 33 计算。
- 模型估计：TCE = [运费 × (1 − 3.75%) − 燃油 − 港口费] ÷ 往返天数，反过来由 TCE 求运费。主要参数：航程单程 5,900 海里（估算），天气余量 5%，航速重载 13 节、压载 12.5 节，往返 46.51 天，每航次燃油 2,864 吨，港口费 15 万美元（假设），燃油价取当月新加坡 VLSFO 估值。这些参数**未与 Baltic 现行 TD3C 规格文件核对**。
- 敏感性区间：燃油价 ±100 美元/吨，同时港口费取 10 万或 25 万美元。
